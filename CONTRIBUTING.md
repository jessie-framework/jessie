# Contributing

Thanks for your interesting in contributing to Jessie! Before contributing , you have to prove that you are an actual person writing code as use of LLMs are not allowed. You are free to do any of the following to prove that you are a human, we are not that bureucratic, just ask for it and start away:

### List of things you can do to prove that you are a human

- Join the [Jessie discord server](https://discord.gg/GFBUKTH3XT)
- Contact another contributor (more like the only contributor but there you go `evolvedpot@gmail.com`)

## Documentation

Documentation is available at the `documentation/` directory at the root of the project.
